Google Drive — облачно резервно копие

Създава отделна частна папка и архивите на приложението в твоя Google Drive. Достъпът е ограничен до файловете, които Swing Signal Monitor създава или изрично му предоставяш.

Това е публичен Client ID, не Client Secret. Не поставяй тук API ключове или пароли.

Не е свързан.

OAuth разрешението е само за файловете, свързани с това приложение (drive.file). Токенът за достъп не се записва в localStorage; след презареждане може да се наложи повторно свързване. Google Cloud Console трябва да има активиран Drive API и OAuth Web Client с origin на GitHub Pages.
