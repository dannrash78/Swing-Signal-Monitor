Настройки на стратегията, връзката и източниците на пазарни данни

Връзка с Backend

Backend URL е адресът на твоя Cloudflare Worker. Той посредничи между инструмента и доставчиците на пазарни данни. Всеки потребител може да използва собствен Worker.

Стратегия

Целта за изход и нивата на спад се използват и в двата списъка.

Data Sources

Избери кои доставчици могат да се използват при Update. Числото определя приоритета: 1 се използва първо, след това 2, после 3. При проблем с първия активен източник инструментът може да премине към следващия.

Исторически дневни данни. Подходящ като резервен източник, но има ограничения на API квотата.

Дневни пазарни данни. Инструментът използва този източник за текущите изчисления, когато е избран.

Алтернативен доставчик за fallback. API ключът се задава само в твоя backend, не в тази страница.

Какво се настройва тук?

  • Backend URL — към кой твой backend да изпраща заявките инструментът.
  • Enabled — дали даденият доставчик може да участва в Update.
  • Priority — редът, в който активните доставчици се използват.
  • API ключовете не се въвеждат тук. Те остават като secrets в твоя Cloudflare Worker.
